EDIT PATH

Reframe first

Open the .insv files in Insta360 Studio, set FlowState and Horizon Lock, reframe, then export 3840×2160 60fps H.264 at 80–120Mbps. Only then take the flat file into iMovie or Final Cut.

Before take-off

  • Set RTH altitude for the exact spot.
  • Keep max distance and altitude modest.
  • Use 4K60 only for walking or slow-car tracking / slow motion.
  • Avoid 4K100. Clear the 49GB storage before the day.
  • QuickShots do not get obstacle sensing: scout the path first.
IMPORTANT

Not an Autobahn chase drone

Keep it close, in visual line of sight, and never launch from a moving car. If the take-off point moves, Return-to-Home can head for the old position.
